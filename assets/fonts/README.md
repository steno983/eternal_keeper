# Typography

- black-chancery.ttf: Black Chancery, Earl Allen / Doug Miles, 1991. Downloaded from https://www.dafont.com/black-chancery.font via its download link. DaFont lists the font in its Public domain / GPL / OFL category. The bundled BLACKCHA.TXT describes its public-domain origins; original author notes are preserved as black-chancery-BLACKCHA.TXT. Used unmodified for display titles, hero names and super names.
- notes.ttf: Caveat, The Caveat Project Authors. Official source: https://github.com/google/fonts/tree/main/ofl/caveat . SIL Open Font License 1.1 included in notes-OFL.txt. Unmodified variable font, rendered at weight 600 for short handwritten annotations.
- ui.ttf: existing project font, retained for controls and numerical information.
- title.ttf: previous project title font, retained for existing references.

Sketchy Notes was evaluated but not included because its free license covers personal use only.
